三个问题：① 找到的 video 素材能不能当低存在感的动态背景，在上面叠字幕动效和核心素材的呈现动效；② 图片运镜能不能比推拉更丰富（对角、横移、2.5D、3D 各角度）；③ 多素材同屏时排版、入场、运镜怎么配合。每组卡后附「定版建议」。

A视频素材做低存在感动态背景（底床）

调研结论（详见 README.md §A）：业界不靠单一"调低透明度"——透明度叠在浅底上会把画面洗成灰雾。标准处理链是 压暗（brightness .35~.5）+ 去饱和（.5~.7）+ 渐变遮罩带（scrim）压住文字区 + 极慢运动（≤0.6%/s 缩放）， 可选模糊（同源模糊底床 20~30px）或双色调（统一到主题色）。底床是 L5/L6 环境层： 前景核心素材入场时它要再让一档（压暗 + 失焦），前景走了再回来。
  • 选片：慢内容（延时、光斑、俯拍、人流虚化），避开可读文字与正脸——它们会抢字幕的视线。
  • 视差：底床 0.5 / 内容 1.0（对应 G2 Plane），底床相机运动只做缩放或极慢横移，不做摇移。
  • 循环：底床片长 < 段落时长时用交叉淡化接缝（0.5s），不硬跳。

A1 · 压暗底床 + 标题逐词升起bed-scrim-typo

底床基准式深底

实拍夜景退成底床：brightness .42 + saturate .55 + 底部 78% 渐变遮罩带；底床 12s 只缩放 1→1.06。标题逐词 26px 升起（错峰 70ms），底部字幕素排。

  • 命门：文字区必须有 scrim——底床上任何亮斑一穿到字后面就不可读；scrim 是渐变带不是整屏罩（整屏罩＝又回到"调透明度"）。
  • 参数：深底 brightness .40~.50 / 浅底方案改用 A3 同源模糊或白色 scrim .75；底床缩放 ≤0.6%/s。
  • 坑：底床里有街牌、正脸；底床与强调色同色系（蓝夜景 + 蓝关键词要么换色要么加白）。
  • 分界：这是"背景面"卡，不是主体卡——同屏主体仍按 ≤3 组算，底床不计入。

A2 · 双色调底床 + 数字生长bed-duotone-wash

统一到主题色数据镜头背景

人流实拍 grayscale → 两层混合（深色 lighten 提黑 + 主题色 multiply 染白）成双色调，任何素材都被拉进同一色板；上面白字数字滚动 + chips 错峰。

  • 命门：先去色再着色（直接叠半透明色块会脏）；两层混合的深色取主题色的暗调，不是纯黑。
  • 参数：grayscale 1 / contrast 1.15 / brightness .62；multiply 层 opacity .85~.95。底床横移 ±20px/14s。
  • 用处：换素材不换气质——一段里连用三条不同来源的 B-roll 底床仍像同一部片。
  • 坑：双色调 + 彩色前景图片会打架（前景照片要么白边卡隔开，要么也去色）。

A3 · 同源模糊底床bed-echo-blur

核心视频素材呈现浅/深底皆可

前景核心视频装白边卡摆在右侧，同一条视频放大 1.25 + blur 26px + brightness .45 铺满当底床——不用找第二条素材，颜色一定和谐。

  • 命门：两条 video 同一 src 同起播（demo 里重播时一起归零）；底床 blur ≥20px 才读作"氛围"而不是"糊了"。
  • 参数：卡宽 55%，白边 10 + 唯一投影；底床 12s 里 1.25→1.32 慢推，前景卡只 1→1.03。
  • 用处：竖屏手机录屏/竖拍素材放横屏（代替黑边）；只有一条可用素材的镜头。
  • 坑：前景卡与底床同速运动（读作整屏在缩放，深度感全丢——两层速度必须错开）。

A4 · 底床让位 + 视差bed-dim-on-focus

G3 让位用在背景上G2 视差

海面实拍底床 brightness .55 慢横移；每张证据照片弹入那一帧底床再压到 .28 并失焦 5px（0.5s），照片退场底床回到 .55；前景层横移速度是底床的 2 倍。

  • 命门：让位与入场同帧起（延后即读作"背景坏了"）；回来的速度要比让位慢一点（.6s vs .5s）。
  • 参数：底床 .55 → 让位 .28 / blur 5px；视差比 0.5 : 1.0（底床 30px 对前景 60px / 9s）。选片教训：城市夜景原片本身太暗，.5 再压就是黑屏——底床选片要看原片平均亮度。
  • 用处：一段口播里连出多张证据，底床全程在，但每次证据上来它都知道退一步。
  • 坑：底床让位用透明度（透出底色变灰）——用 brightness 才是"暗下去"。
定版建议：A1 作为"底床基准式"进 shot-design.md 背景面菜单（空间基底新增「实拍底床」一项）；A3 单独成卡（它同时解决竖屏素材问题）；A2/A4 的处理链写进 design-language 环境层参数表，不必各自成卡。

B图片运镜拓展（在已有六式之外）

已有：缓推 / 缓拉 / 横向摇移 / 3D 立面倾斜 / 环绕漂移 / 长页兴趣点巡游。调研结论（README §B）：缺的不是更多"姿态"，而是 ①带方向的复合运动（推与移同时，两点之间）、②假深度（单图 2.5D）、③有事件感的 3D 姿态变化（从一个角度"拿起来/转过来"）， ④变速（速度曲线本身是语言）。所有卡沿用运镜共有纪律：相机层唯一被 transform、末速非零、≤1.2 倍、素材分辩率 ≥ 画幅 × 最大缩放。

B1 · 对角推移diagonal-dolly-pan

两点之间推 + 移复合

镜头从兴趣点 A（1.08 倍）沿对角线推到兴趣点 B（1.22 倍）：缩放与位移同一条曲线（camEase 末速 0.6），到 B 后按末速续走。位移量由"把 B 搬到画面正中"反解，不手敲。

  • 命门：位移与缩放必须同一进度驱动（分两条 tween 会在中途甩出一段横漂）；B 点由反解得出并钳制在不露边范围内。
  • 参数：zoom 1.08→1.22 / 7s / 末速比 .6；两点距离 ≤ 画面对角 45%。
  • 分界：slow-push-in 是一点原地推；sway-parallax 是不变焦横移；本卡是"从这儿到那儿"——有叙事方向。
  • 坑：A、B 挑在同一水平线（那就是横移）；推到 B 后停死。

B2 · 切片视差 2.5Dsliced-parallax-2.5d

单图假深度不需抠像

同一张风景图叠三层，用渐变蒙版切成远/中/近三个横带；横移时三层速度 0.65 : 1 : 1.55，近层再多推 4%。蒙版重叠区做 8~10% 的柔边，把三层错位藏进过渡带。

  • 命门：柔边宽度 ≥ 两层最大错位量（否则过渡带出现双影）；层的外扩量 ≥ 该层位移量（不露底）。
  • 适用：有明确远中近分层的风景/街景；不适用人物、建筑立面（水平切会切断竖直结构）。
  • 进阶：真 2.5D 要抠前景主体（host-footage.md 的 CPU 分割可直接复用于照片主体）+ 背景补全，深度图工具见 README。
  • 坑：速度比拉到 2 以上（过渡带撕裂）；三层都加缩放（变成呼吸）。

B3 · 俯拍起身flatlay-rise

3D 姿态事件俯 → 正

照片以 58° 俯角"躺"在桌面（带接触阴影）静置 0.4s，1.3s 内起身到正视并推近，之后缓推续走 5s；结尾 1.1s 放回去。起身是事件，允许收住；hold 期不许停。

  • 命门：阴影跟姿态走（躺着时阴影大而近、立起来后小而远）；起身与推近同一条 inOut。
  • 参数：rotateX 58°→0 / 1.3s power2.inOut；scale .9→1.0→1.06；perspective 1000。
  • 分界：tilt-3d-page 是"立面姿态 + 静态展示"，本卡是"从俯到正"的动作——讲"我们拿到了这份东西"时用。
  • 坑：俯角 >65°（读作一条线）；起身太快 <0.8s（像弹起）。

B4 · 侧角转正swing-to-face

3D 姿态事件侧 → 正

照片从 −38° 侧角、偏左 140px 起，2.2s 转到正对镜头并推到 1.0，随后继续极慢推到 1.05 并带 +3° 的反向余摆——转正是事件，余摆是"永不静止"。

  • 命门：转正后必须过 0°一点再回（余摆），停在 0° 那帧就是 PPT；阴影随角度往反侧偏移。
  • 参数：rotateY −38°→0→+3° / 2.2s + 5s；translateX −140→0；perspective 1100。
  • 分界：orbit-drift 是围着素材小幅漂（无始无终）；本卡有明确"来到正面"的一拍——讲"现在正式看它"。
  • 坑：起始角 >45°（看不清是什么）；转正与推近分两条曲线（先到位再放大，读作两个动作）。

B5 · 变速摇移ramp-pan-sweep

速度曲线即语言同图两点

宽幅素材放大到 1.5 倍，镜头在左端停 1.2s（带漂）→ 0.55s 甩到右端（运动模糊随速度 0→8px→0）→ 停 1.6s → 0.9s 慢一点回到中段。停是讲，甩是"看那边"。

  • 命门：模糊量跟速度走（峰值在中点），到位帧模糊必须为 0；停留段仍有 ≤6px 漂移。
  • 参数：甩 0.55s power3.inOut / 峰值 blur 8px；停留 1.2~1.8s；素材放大 1.5 保证两端不露边。
  • 分界：sway-parallax 是匀速 ≤190px/s 的慢摇；whip-pan-transition 是两镜之间的转场；本卡是同一张图里两处之间的"甩看"。
  • 坑：甩两次以上（晕）；甩完不停留（观众没看到落点）。
定版建议：B1、B5 直接补进「运镜」类（各自有独立语义：方向 / 变速）；B3、B4 合并成一张「3D 姿态事件卡」（俯→正 / 侧→正两个 preset）；B2 先留在实验室，等抠像版 2.5D 一起定。

C多素材同屏：排版 × 入场 × 运镜

调研结论（README §C）：多素材的问题不是"怎么摆下"，而是观众该看哪。三条原则： ①排版先定关系（并列→等大网格 / 主次→一主两辅 / 对比→双分屏 / 序列→传送带 / 汇聚→网格收成一个）； ②入场有先后有方向（错峰 100~150ms、同向、全组同时同速淡入＝PPT）； ③任一时刻只有一个主角——焦点接力靠"其余降权"（brightness .55 / scale .98）而不是主角放大很多。 运镜在多素材上只做两种：横向巡览停靠、推入单个再拉回全景。同屏主体组 ≤3、留一个空象限的预算不变。

C1 · 一主两辅 + 焦点接力hero-duo-layout

C2 · 对比双分屏（滑动揭示）split-compare-slider

对比关系同机位两图

C3 · 照片墙推轨gallery-wall-dolly

序列 / 并列相机在多素材上巡览

三张照片挂在一面 −12° 的 3D 墙上；镜头先全景 0.8s，再依次推轨停靠每一张（1.0s 移动 + 0.9s 停靠，停靠时其余两张压暗 .5），最后拉回全景。

  • 命门：每一站的缩放绕当前照片发生（transform-origin 反解到该照片中心，同 stage-keyframe-tour）；停靠段照片内部有 1→1.03 微推防死。
  • 参数：全景 z .72 / 停靠 z 1.15；墙 rotateY −12°；移动 1.0s power2.inOut。
  • 分界：stage-keyframe-tour 巡的是一张长页里的兴趣点；本卡巡的是多张独立素材——"接下来三个例子"。
  • 坑：站与站之间不停（观众读不完）；照片尺寸不一（墙面读作乱）。

C4 · 传送带列举 + 减速停靠filmstrip-conveyor

序列关系列举镜头

六张素材接成一条传送带匀速左行（一组 9s），经过中线的那张按距离放大到 1.08 并提亮；讲到关键一张时传送带减速到 0.25 倍停 1.4s 再恢复——速度就是讲述节奏。

  • 命门：放大/提亮按"离中线的距离"每帧算（不是到点触发），经过是连续的；减速用 timeScale 缓动，不是硬停。
  • 参数：匀速 176px/s（240 卡 + 24 间隙 ÷ 1.5s）；中线放大 1.08；减速 0.25× / 1.4s。
  • 分界：shot-design ② 提过"列举用传送带流"但无卡；本卡补上，且带"减速停靠"语法（对齐 evidence-scroll-tour 的滚动纪律）。
  • 坑：传送带速度 >220px/s（扫读跟不上）；一组少于 5 张（循环接缝太频）。

C5 · 网格收成主角grid-to-hero

汇聚 → 聚焦图 + 视频混排
