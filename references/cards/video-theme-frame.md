## 输入类型
| 口播视频 | B-roll 视频 | 图片 |
|---|---|---|
| 可（引用别人的口播 / 采访片段——"他是这么说的"，框就是引号）；本片主播自己的画面不进框 | **默认输入**（录屏 / 实拍单条当主体） | 不适用（框在说"这是一段录像"，画面不动一眼假；图用 media-pop-in / slow-push-in / tilt-3d-page） |

命门是**框是一个有出处的物**——窗口钮、齿孔、图注、尺寸线都能一句话说出"它是什么"；框里放的是真在动的视频。

## 常用场景
1. 网页 / 桌面录屏当证据（复古浏览器 · 笔记本：一眼"这是屏幕"，又不是本片自己的 UI）
2. 引用别人的成片 / 采访片段（35mm 胶片 · 杂志相框：把"引用"说成"档案"）
3. 单条 B-roll 撑一整句而画面里没有别的主体（拍立得 · 邮票：给它一个"物"，不裸贴满幅）
4. 方法论 / 拆解调性的片子（工程图纸：与 G5 线稿示意图同一套墨线，全片一个体系）

## 意图
单视频镜头最常见的三种做法都弱：**裸贴满幅**——观众分不清这是本片画面还是引用的素材，也没有任何"物"可看；
**裸放一张白卡**——像贴了一张会动的照片；**装一个假播放器**——进度条、播放键、时间码一装上，观众就会拿它对画面里的动作，
对不上就是撒谎，对得上也只是把一个 UI 控件当装饰（2026-09-07 用户定版：不要进度条 / 播放键，要有创意的设计元素的边框）。
主题边框把视频变成一个**有出处的物件**：复古窗口说"这是屏幕里的东西"，胶片说"这是档案"，杂志图注说"这是一张配图"，
图纸说"这是被拆解的对象"。框的语汇替口播交代了素材的身份，整镜也有了除视频以外的第二层可看的东西。

做对的命门：
1. **框是"物"不是 UI**：每式的元素都是那个物本来就有的（窗口钮 / 齿孔 / 图注 / 尺寸线 / 摄像头点），没有任何假控件；八式之外别自造"科技感边框"。
2. **动作只有四段**：落位 0.45s → 装饰接力（描线 / 淡入 / 展开，≤1.35s 内全部画完静置）→ 整框极缓推 1→1.03 → 退场 0.35s。不弹不摆、不呼吸不扫光。
3. **视频画面零处理**：不加滤镜 / 不缩放 / 不淡入淡出，画面的活由整框极缓推负责（G1 相机）；给视频加特效等于承认视频不够看。
4. **一片一式**：同一支片里所有单视频镜用同一式（design-language §0.4 一致性），选式写进 SHOTBOOK 蒙皮行；demo 的巡演只为展示。

## 动效核心
- **落位**（八式同一节拍）：opacity 0→1 + scale .96→1 + y 16→0，0.45s `power3.out`（拍立得 y 24→0，并固定倾斜 −1.5°）。
- **装饰接力**（落位起点 +0.5s 起，各式不同，全部 ≤1.35s 画完）：
  - 复古浏览器 / 35mm 胶片 / 拍立得 / 笔记本 / 邮票：**没有装饰动作**——物本身已经够看，落位即静置。
  - 杂志相框：通栏细线 `scaleX 0→1` 0.4s（origin left）→ 图注与页码淡入 0.3s（+0.15）→ 左下短线 0.3s（+0.2）。
  - 工程图纸：外线机器一笔画 0.6s（`pathLength=1` dashoffset，power2.inOut）→ 四角十字各 0.25s 错峰 0.06（+0.45）→ 尺寸线 0.4s（+0.65）→ 刻度 0.3s linear（+0.85）→ 等宽小字淡入（+1.05）。
  - 双发丝线：外圈淡线淡入 0.3s → 四角短标各 0.25s 错峰 0.06（+0.15）。
- **整框极缓推**：落位后 scale 1→1.03 匀速到退场（linear，末速非零）；这是画面唯一持续的运动。
- **退场**：opacity→0 + scale→.98，0.35s `power2.in`。
- **舞台底**：邮票式舞台改极浅灰 `#f0f0f2`（白边要显形），其余白底；胶片式是浅底上唯一的一块深 tile。
- 装饰文字（窗口标题 Untitled / 地址栏 http:// / 图注 FIG. 01 / 页码 024 / 片号 24 · KODAK 400 / 尺寸 768 · SCALE 1 : 1）**是装饰不是信息**，进片可换可空。

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| `frame` | 八式之一 / `tour` | 成片单选一式；`tour` 只给 demo 与选式用 |
| `hold` | 口播句长 | 退场起点；demo 1.85s；<1.5 框还没看清就走 |
| `landIn` | 0.45s | <0.3 像弹窗；>0.7 观众等框等到不耐烦 |
| `decorAt` | 0.5s | 装饰在落位将完时起笔最顺；早于 0.4 与落位抢同一条视线 |
| `push` | 1.03 | 镜头 >10s 可到 1.05；>1.06 框边逼近安全区 |
| `exit` | 0.35s | 与下一镜的运动承接对齐（cinematography §3） |
| `ink` | 本片 ink | 装饰线 / 装饰字的墨色；深底片换亮 hairline |
| `label` / `sub` | 各式默认 | 装饰文字；空字符串 = 不显示 |

## 已知坑
- 在框上加进度条 / 播放键 / 时间码"更像播放器"——观众会拿进度对画面，对不上就是假的；对得上也只是 UI 控件不是设计。已被用户明确否决。
- 一支片里换着式用（这镜浏览器、下镜胶片）——框的语汇是在交代素材身份，换式 = 身份乱；一片一式。
- 视频里再套一层淡入 / Ken Burns / 滤镜——框已经在极缓推，画面再动就是双重运动。
- 用截图（静图）冒充录像放进框——框说"这是录像"，画面不动一眼假；静图请回 media-pop-in / tilt-3d-page。
- 装饰文字写成信息（把标题 / 来源写进窗口标题栏）——它们是装饰，字号 9~12px 本来就读不清；信息走字幕 / 花字层。
- 复古浏览器式用在讲本片自己产品 UI 的镜头——两层 UI 叠着，观众分不清哪层是内容；产品界面卡（chat-gpt / claude-code 类）不套框。
- 拍立得倾斜 >3° 或做"落下回弹"——读作贴纸 / 动效模板；固定 −1.5°、直落。

## 动效范围
- 属于本卡的：八式的造型与各自的装饰接力（描线 / 淡入 / 展开的先后与时长）；落位 0.45s、整框极缓推 1→1.03、退场 0.35s 这套共用节拍；"框是物、画面零处理、一片一式"三条纪律。
- 不属于本卡的：示意视频（demos/_lib/media/v-typing.webm）、装饰文字的具体内容、demo 巡演的顺序与 2.2s/式（仅示范，成片一镜一式）、浅底舞台。
- 迁移接口：**皮按风格档蒙**（design-language §0.4）——装饰线 / 装饰字换本片 ink；深底片：复古浏览器换深灰铂金、杂志 / 图纸 / 双发丝线换亮 hairline、拍立得 / 邮票保留白（它们本来就是白物）；框尺寸按素材比例（16:9 / 9:16 手机录屏用笔记本式改成手机式：竖屏深框 + 顶部药丸）与主列宽（≤1440@1080p）。
- 底色要求：白底即可；邮票式必须极浅灰底；深底片选式先看框在深底上是否还是"物"（胶片式在深底上会消失）。

## 落位自检（选卡时抄进 SHOTBOOK 该镜自检列）
- 框四边在 action-safe（96@1080p）内；框底边到字幕带顶 ≥60px；框与同屏其他主体包围盒不相交（胶片式通幅例外，但字幕带必须在胶片带之外）。
- 全片单视频镜同一式，式名写在每镜蒙皮行；装饰线颜色 = 本片 ink。
- 装饰接力在落位 +1.35s 内全部画完并静置（抽 +1.5s 帧核：没有任何东西还在动，除整框极缓推）。
- 视频层没有任何 filter / 二次 transform；整框推 ≤1.05。
- 框上没有进度条 / 播放键 / 时间码之类的假控件（SKILL.md ③「单视频镜头要有主题边框」）。
