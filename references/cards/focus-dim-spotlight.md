优先级: P0
代码: template/cards/focus-dim-spotlight.tsx
一句话: 讲到哪里哪里亮——目标行/卡片保持原亮并点亮发光描边，其余整屏压暗 40%（或整页高斯模糊只留目标清晰），焦点随口播 0.2s 滑到下一目标，讲完整体 0.4s 恢复
适用: 口播出示表格/清单/代码/多卡版面，逐项讲"这一行→下一行"的时刻；也用于整屏退让给一句结论。财经财报拆解、AI 工具演示、评测参数对比等信息密度高、需要"我说到哪你看哪"的冷静调性
时长: 起手静置 0.45s → 焦点建立 0.3s（压暗缓入 + 描边撑开同帧）→ 每目标停留 1~1.5s、焦点跳转 0.2s（可连续 N 次）→ 讲完整体恢复 0.4s；四目标一段约 8s
能量: 低
类别: 强调标注

## 意图
表格/清单/多卡版面上同时有十几个数字，口播念到第三行时观众还在第一行——聚焦压暗把
"视觉权重"整块搬到目标上：目标不动、不放大、不加色，**只是周围全暗下去**，观众
无从选择只能看那一行。它和荧光笔的分工是尺度：荧光笔在**一行文字内**画重点（笔触、
色块、行级），本卡在**版面尺度**上切焦点（一整行 / 一张卡 / 一个区域，靠明度差而非涂色）。
命门：**目标本身零改动**（一压暗就想给目标加放大加换色，三件套一起上就成了 PPT 强调预设，
本卡的力量全在"其余变暗"这一个动作上）、**焦点是滑过去的不是切过去的**（0.2s 位移让
观众眼睛跟得上"从上一行到这一行"，硬切等于每次重新找目标）、**讲完必须整体恢复**
（暗着不收观众会以为画面就是这么暗的，聚焦感只在"暗-亮"的对照里成立）。

## 动效核心
- 结构：一个**聚光窗口**元素浮在内容之上，用超大 spread 的 `box-shadow: 0 0 0 9999px rgba(0,0,0,dimTo)`
  把窗口以外的整屏压暗（容器 `overflow:hidden` 裁掉溢出）；移动/缩放这个窗口 = 焦点跳转，
  非目标区暗度自动跟着换。目标本身**不改任何属性**
- 目标矩形运行时测量（`getBoundingClientRect` 除以外壳缩放系数换回设计坐标）：换目标只换选择器，不改坐标
- 通道①**压暗**：非目标区 `dimTo` 0.35~0.45（白底）暗度蒙层 0.3s `power2.out` 缓入
- 通道②**模糊**：整页 `filter: blur(8px)`，仅目标区清晰（目标层不带 filter 或用 backdrop 反遮罩）；
  焦点切换时清晰区/模糊区互换 0.2s——比压暗更"景深"，代价是文字模糊态不可读、单目标场景才用
- 通道③**描边**：目标被圆角发光框圈住——`opacity 0→1` + `scale 0.95→1` 撑开，0.3s `power3.out`，
  外挂一层 `box-shadow` 辉光单独做 `sine.inOut` yoyo 微脉动（半周期 1.6s，防死、不是闪烁）；其余仍压暗
- 三通道**任选/可叠**：①是底座，③叠在①上（demo 主演）；②与①是替代关系（同时上会糊成一团）
- 焦点跳转：窗口与描边框**同一条 tween** 同步位移+改尺寸，0.2s `power2.out`，可连续 N 次
- 尺度可变：同一个窗口从"一行"形变到"整张卡"只是改 width/height（0.45s `power2.out`）——
  焦点从局部放大到版面，用来收束"四行放在一起看"的结论句
- 收尾：蒙层 `opacity → 0` 0.4s `power2.out` 整体恢复；描边先于蒙层 0.25s 退场
- 字幕/花字层在蒙层**之上**（`z-index` 高于聚光窗口）——字幕是叙述层，不参与被压暗

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| `dimTo` | 0.40（白底）/ 0.20~0.25（深底） | 非目标区暗度；<0.25 在白底上几乎看不出压暗、强调失效，>0.55 上下文变成一整块黑、观众想回看读不到 |
| `dimIn` | 0.30s | 蒙层缓入；<0.15s 读作切黑闪一下（像掉帧），>0.5s 焦点来得比语音晚、跟不上台词 |
| `jump` | 0.20s | 焦点跳到下一目标；0（硬切）观众每次要重新找目标，>0.4s 焦点在半路时台词已经念完了 |
| `hold` | 1.0~1.5s | 每目标停留，对齐这一行的台词；<0.7s 只够扫一眼读不到数字，>2.5s 该切下一卡了 |
| `ringFrom` | 0.95 | 描边撑开的起始倍数；1.0 读作贴上去的静态框，<0.85 变成弹框入场、抢戏 |
| `glowHalf` | 1.6s | 辉光脉动半周期；<0.8s 读作报警闪烁，脉动幅度为 0 则长停留时画面死 |
| `blurPx`（通道②） | 8px | 非目标区模糊半径；<5px 读作没对上焦的失误，>14px 上下文彻底消失、失去"同一张表"的连续感 |
| `restore` | 0.40s | 整体恢复；不恢复观众会把压暗当成画面底色，聚焦感事后归零 |

## 已知坑
- 压暗的同时给目标加放大 / 换色 / 加投影——三件套一起上就是剪映"强调"预设，本卡的克制感尽失；**目标零改动**是本体纪律。
- 焦点硬切（`jump = 0`）——每次跳转观众都要重新在版面里找目标，等于每行都从头聚焦一次。
- 蒙层压得太黑（>0.55）——上下文被"删掉"，观众失去对照能力，反而想回看却读不到（同 highlighter-sweep 的 `dimTo` 坑）。
- 讲完不恢复——暗态成了新的常态，下一次聚焦没有对照、读不出"这里亮了"。
- 字幕/花字被一起压暗——叙述层跟着变灰，观众以为是渲染错误；字幕必须在蒙层之上。
- 通道②模糊用在**多目标连续跳转**上——每次跳转整页 blur 重算，观众眼睛在"糊-清"之间反复重新对焦，几次就晕；连续跳转用①+③。
- 发光描边用纯色硬框无辉光、或辉光做成闪烁——前者读作表单 focus 状态（浏览器 outline 感），后者读作报警；要的是连续呼吸的"点亮"。
- 描边框贴着目标边缘零留白——框压在文字/卡片边线上读作选中态；左右内缩到内容盒、上下外扩 3px 左右。

## 复用指引
- Remotion/tsx（skill 首选）：template/cards/focus-dim-spotlight.tsx——自包含单文件，复制进工程即可用；参数在顶部 CONFIG，时长/尺寸在 meta。
- HTML/GSAP：demos/focus-dim-spotlight/index.html。换目标改 `.trow.data` 选择器（矩形运行时测量，坐标不用改）；换聚焦几何改 `focusInsetX` / `focusPadY`；节奏全在顶部 `CONFIG`（`dimIn` / `jump` / `hold` / `restore`）；焦点色一个 CSS 变量 `--focus`；暗度 `dimTo` 直接写进 `.spot` 的 `box-shadow` spread 色值。核心可摘走部分 = `CONFIG` + `DemoShell.register` 回调体（含 `rectIn` / `focusBox` 两个测量函数）。通道②改成给内容容器上 `filter: blur()` 并把目标行提到未模糊的同位克隆层。
- Remotion 移植：聚光窗口用一个绝对定位 div，`boxShadow: \`0 0 0 9999px rgba(0,0,0,${interpolate(frame,[d,d+dimInF],[0,dimTo])})\``（外层 `overflow:'hidden'`）；焦点跳转把 `left/top/width/height` 各自 `interpolate(frame, [t,t+jumpF], [from, to], {easing: Easing.out(Easing.quad)})`，目标矩形在构建时静态算好（Remotion 无外壳缩放，直接写设计坐标）；描边 `scale: interpolate(..., [0.95,1], {easing: Easing.out(Easing.cubic)})`；辉光脉动 `opacity: 0.35 + 0.65*(0.5+0.5*Math.sin(frame/fps*Math.PI/glowHalf))`；通道②用 `filter: \`blur(${interpolate(...)}px)\`` 作用在内容 Sequence 上。
- 剪辑软件对应物：剪映——新建黑色色块铺满画面、不透明度 40%，加"蒙版→矩形"并**反转蒙版**，蒙版位置/大小打关键帧即焦点跳转；发光框用"边框"贴纸或矩形描边素材 + 发光滤镜；AE——黑色 Solid + Mask（Mode 设 Subtract）、Mask Path 关键帧移动，或 Set Matte；发光框用 Shape Layer 描边 + Glow 效果，Opacity 表达式做呼吸；通道②用 Gaussian Blur + 反转蒙版的调整图层；CapCut——同剪映的 inverted mask keyframe 做法。

## 动效范围
- 属于本卡的：聚光窗口以外整屏压暗至 `dimTo`（0.3s 缓入 `power2.out`）；焦点在目标间**同步位移+改尺寸**跳转（0.2s `power2.out`，可连续 N 次）；目标发光描边亮起（`opacity 0→1` + `scale 0.95→1`、0.3s `power3.out`）与辉光 `sine.inOut` 微脉动（半周期 1.6s）；焦点从"行"形变到"整卡"的尺度切换（0.45s）；讲完整体恢复（0.4s，描边先于蒙层退场）；三通道（压暗 / 模糊 / 描边）的组合纪律（①是底座、③叠①、②替代①）；**目标本身零改动**与字幕层不被压暗这两条硬约束。
- 不属于本卡的：demo 里的灰阶数据表卡（排版、字号、假数据）、角标主持人（数字人是演示语境素材）、示例台词与字幕切换、右上角"通道①/③"注记、`--focus: #ffb020` 这个具体焦点色、卡片圆角与边框样式。
- 迁移接口：`dimTo` **随底色明度取值**（白底 0.4 / 深底 0.2~0.25，深底压暗过头会糊成一片黑）；焦点色一个 token `--focus`（深底换高明度色）；目标 = 任意 DOM 元素/坐标矩形（运行时测量，换内容不改代码）；`jump`/`hold` 对齐词级语音时刻；换尺寸时描边线宽与圆角、`focusInsetX`/`focusPadY` 按画幅等比缩放，`9999px` spread 无需改（只要容器裁剪）；通道②只需把 `blurPx` 换到内容容器的 `filter` 上，时序原样复用。
- 底色要求：白底即可（压暗蒙层在浅底对比最强，是本卡最自然的场景）。深底截图/终端画面同样成立，但 `dimTo` 必须减半、焦点色换高明度值，否则暗区与暗底并成一块、焦点无处可寻。
