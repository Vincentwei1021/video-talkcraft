name: freeze-frame-annotate
标题: 定格圈注
一句话: B-roll 正常播 1.3s 后瞬时定格（配 4 帧 18% 白闪当快门），停 8 帧让观众看到"停了"，再一条手绘感马克黄椭圆 8 帧描边圈住目标、箭头 6 帧点题、标签浮出，hold 1.6s；圈注淡出的同一帧解冻，视频 1.4× 追一秒补回时长再回正常速——定格期间画面绝对静止，只有圈和字在动
适用: 操作演示 / 纪录片 / 体育游戏解说 / 网友投稿视频里"注意这个细节"：把正在动的画面停下来指出一处再放行。输入是 B-roll 视频（库内唯一吃视频的标注卡）；人物不参与
时长: 5.9s（0～1.3 正常播 → 1.3 定格 + 白闪 → 1.57 画圈 8 帧 → 1.84 箭头 6 帧 → 1.94 标签 → 3.64 解冻 1.4× 追一秒 → 4.64 回 1× → 5.5 退场 0.4s）；成片定格时刻按口播"注意"落在哪个字，hold 按讲完这一处的句长
能量: 中低（定格那一下是唯一打击点，之后是凝视）
类别: 强调标注
优先级: P1
代码: template/cards/freeze-frame-annotate.tsx
---

## 输入类型
| 口播视频 | B-roll 视频 | 图片 |
|---|---|---|
| ✗ 人物不参与（定格讲者本人是另一件事） | ✓（默认输入）实拍 / 录屏 / 投稿视频，cover 铺满 | ✗ 静图不需要定格——直接用 `hand-drawn-ellipse` / `scribble-annotation` |

真 B-roll 经 `src` 注入，时间重映射在 Remotion 里用 `<Freeze frame>` 包住 `<OffthreadVideo>`（正常段 = 当前帧、定格段钉住、解冻段 1.4× 追赶）；demo 用 footage 占位（灰调渐变 + 匀速漂移亮带，定格 = 漂移相位钉住）。

## 常用场景
1. 操作演示 B-roll 里定格指出手势 / 键位（demo 演的：注意他的左手）
2. 纪录片式："注意这个镜头里的背景"
3. 体育 / 游戏解说式的动作分解：停下来圈住那一步
4. 网友投稿视频里定格圈出细节

## 意图
库里所有标注卡（荧光笔、圈注、箭头、放大镜、聚焦压暗）的输入都是图或文字——taxonomy 输入类型索引里"强调标注 × B-roll 视频"那格是空的。视频在动，标注画上去要么跟不上目标（不追踪），要么追踪成本高；电影和体育解说的解法是**先把时间停住**：定格 → 圈 → 放行，观众看到"停了"就知道接下来是重点。做对五条：
1. **定格要干脆**：源时间斜率瞬间归零（无缓入），任何减速进定格都读作卡顿掉帧。
2. **定格段 ≥45 帧**：凝视不够长圈注就没意义（宁慢勿快）。
3. **圈注对象锐利、画完静置**：定格帧模糊就换一帧；圈画完不抖（用户禁 line boil，手绘感来自路径本身的不规则）。
4. **解冻补时**：1.4× 追一秒把停掉的时间补回来再回 1×，>2× 读作快进。
5. **一个镜头只能有一个时间操纵者**：与 `evidence-scroll-tour` 等任何动时间轴的卡同镜互斥。

## 动效核心
- **几何**（960×540）：B-roll cover 铺满全幅（舞台底 #1d1d1f 兜底）；圈注椭圆手绘感路径以目标为中心（demo 圈住画面中心 (480, 268)，rx ≈150 / ry ≈96，四段三次贝塞尔略不规则，长 786）；箭头从标签右下指向椭圆左上缘（(296,166) → (366,196)，长 114，带两笔箭头）；标签 @ (92, 96) 30px/700 白字 + `text-shadow 0 2px 10px rgba(0,0,0,.7)`，副行 16px/500 白 80%；定格徽标右上 (right 40, top 30) 等宽 14px 字距 1.5 白 75%，文本 `FREEZE · 00:01.30` 由 freezeAt 生成。
- **源时间重映射** `src(t)`：`t < 1.3 → t`；`1.3 ≤ t < 3.64 → 1.3`（钉住）；`3.64 ≤ t < 4.64 → 1.3 + 1.4·(t − 3.64)`；之后 `2.7 + (t − 4.64)`。Remotion：`<Freeze frame={round(src·fps)}><OffthreadVideo/></Freeze>`；demo 占位：亮带 `translateX(−40·src)`。
- **定格帧**：白闪 0 → 0.18 用 0.04s（≈1 帧）、再 0.12s 落回；徽标 0.2s 淡入。
- **圈注**：1.57s 起椭圆 `stroke-dashoffset 786→0` 0.27s（8 帧）`power1.inOut`；1.84s 起箭头 `114→0` 0.2s（6 帧）`power2.out`；1.94s 起标签 0.3s `power2.out` opacity 0→1、y 6→0。马克黄 #ffd60a 5px 圆头。
- **解冻**：3.37s 起圈 / 箭头 / 标签 / 徽标一起 0.27s 淡出；3.64s 那一帧源时间开始以 1.4 斜率走，4.64s 回 1。
- **退场**：5.5s 画面 opacity→0 0.4s `power2.in`，5.9s 结束。

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| `freezeAt` 定格时刻 | 1.3s | 按口播"注意"那个字落；定格前至少 1s 正常播，观众要先知道画面在动 |
| `flash` 快门白闪 | 0.18 / 4 帧 | 0.12～0.25；>0.30 读作曝光事故，0 则定格像掉帧 |
| `drawDelay` 定格后停顿 | 0.27s（8 帧） | 先让观众看到"停了"再画；<4 帧圈和定格读作一件事 |
| `draw` / `arrow` | 8 帧 / 6 帧 | 太慢像加载动画；太快看不到"画"的过程 |
| `hold` 圈注停留 | 1.6s | 定格总长 ≥45 帧（宁慢勿快）；按讲完这一处的句长伸缩 |
| `catchup` 追赶倍率 | 1.4× / 1.0s | 1.25～1.6；>2× 读作快进，1.0 = 不补时（时长就多出定格那段） |
| 圈注颜色 | 马克黄 #ffd60a 5px | 视频上蓝线常与画面同色；黄在实拍里最稳；深色画面可换白 |
| 圈注几何 | 目标 bbox 外扩 20～30 的椭圆 | 太紧读作描边，太松读作"大概这一片" |

## 已知坑
- 定格带缓入（速度渐慢到 0）——读作卡顿 / 掉帧；斜率必须瞬间归零。
- 定格段不到 45 帧——圈还没看清就放行，凝视不成立。
- 圈注加 feTurbulence 抖动 / line boil——用户 2026-09-04 定版禁止；画完静置，手绘感靠路径不规则。
- 定格帧本身模糊（运动模糊帧）——圈注对象要锐利，往前后挪几帧找清晰帧。
- 圈注用强调蓝——实拍里蓝天 / 屏幕 / 衣服常同色，读不出；用马克黄或白。
- 解冻直接 1× 续播——镜头总长多出定格那段，口播已经讲到下一句；1.4× 追一秒补回。
- 与 `evidence-scroll-tour` / 变速卡同镜——两个时间操纵者互相打架；一镜一个。
- Remotion 里用 `playbackRate` 或真 pause 做定格——OffthreadVideo 不支持逐帧变速；正解是 `<Freeze frame>` 时间重映射。

## 动效范围
- 属于本卡的：源时间重映射（正常 → 钉住 → 1.4× 追赶 → 1×）；定格帧 4 帧白闪 + 徽标；8 帧椭圆描边 + 6 帧箭头 + 标签的串行；圈注静置不抖；解冻同帧圈注淡出。
- 不属于本卡的：footage 占位、圈注的具体路径坐标、标签文案、马克黄以外的配色选择。
- 迁移接口：`src / label / sub / ellipsePath / arrowPath`；`freezeAt / hold` 按口播；1080p 输出描边 5→10px、标签 30→60 / 16→32、徽标 14→28。
- 底色要求：B-roll 自身就是底；demo 占位铺满舞台，成片换真 B-roll（cover）；圈注颜色按画面主色反选（黄 / 白）。

## 落位自检（选卡时抄进 SHOTBOOK 该镜自检列）
- 定格帧号 = 口播"注意"字的时间戳所在帧，且该帧锐利（前后 ±3 帧内挑最清晰的一帧，`ffmpeg -ss` 抽帧核对）。
- 圈注椭圆几何由目标 bbox 反推（外扩 20～30，中心重合），箭头尖端落在椭圆缘上、不戳进目标；标签不压目标、不入字幕带、不入人脸安全区。
- 定妆帧两张：定格期（`shot-at 2.2`）核对"圈住目标 + 箭头 + 标签在场、画面静止"；解冻后（`shot-at 4.2`）核对圈注已全撤、画面在动。
- 定格段总长 ≥45 帧（demo 1.3→3.64 = 70 帧）；解冻追赶 ≤1.6×。
- 同镜没有第二个动时间轴的卡；镜头总长 = 口播句长（补时后源视频进度与真实时间重新对齐）。
