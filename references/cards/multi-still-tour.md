## 输入类型
| 口播视频 | B-roll 视频 | 图片 |
|---|---|---|
| 不适用（运镜是给素材的；人在场用 `stage-keyframe-tour` 之外的 D 组并列句卡） | 可（每站一段短视频，停靠那 1s 是它的戏；混放时统一到同一外框比例，裁切不缩放） | **默认输入**（wall 三张同尺寸、timeline 3~5 站每站一张） |

wall 是"三个平级案例"，timeline 是"有先后的几站"——先定关系再选式；两式不在一镜里连用。

## 常用场景
1. "接下来三个例子一个一个看"：三张代表作挂墙逐个停靠再拉回比较（demo wall）
2. 成长史 / 版本演进："从一台笔记本到一间工作室"四站横移（demo timeline）
3. 作品集 / 案例集巡览、三个方案巡完再拉回全景比较（wall）
4. 事件梳理 / 年度回顾：3~5 个时间点沿一条线走完再看全条（timeline）

## 意图
口播"一个一个讲"几张图，最省事的做法是逐张全屏切——但观众看完不知道它们的关系（是三个平级案例？还是先后四站？）。
把几张图挂进一个有空间关系的"世界"，让相机去巡，观众就同时得到"逐个看"和"它们在哪儿"两层信息。做对的命门：
1. **相机层是唯一被 transform 的元素**：`transform-origin: 0 0`，每一站用 `camTo(z, px, py)` 反解出 `scale / x / y` 把目标点搬到画心——**缩放绕当前图发生**。用固定原点 + 位移去凑，zoom 变化时会甩出横向漂移，读作"镜头在找东西"（`stage-keyframe-tour` 同一条纪律）。
2. **停靠段真静止，但当前图内部微推**：本卡是停靠类（`stage-keyframe-tour` 例外），相机在 hold 里不续走；防死的责任交给当前图内部 1→1.03 的微推（wall）或当前站 1.03 点亮（timeline）——画面每帧都在变，但"停下来看这一张"的语义不被破坏。
3. **巡完必拉回全景**：观众刚看了三处细节，需要一眼知道它们在整体里的位置；拉回后的停留是有意的（timeline 1.2s），停留结束与字同收。

## 动效核心
- 共用结构：`.cam`（相机层，`position: absolute; inset: 0; transform-origin: 0 0`）→ 世界坐标里的若干 `.photo`（白边卡 padding 10、圆角 12、投影 `0 12px 60px rgba(0,0,0,.22)`，内部 `.frame` 裁切 + `.ph` 素材）。`camTo(z, px, py) = { scale: z, x: 480 − z·px, y: 270 − z·py }`——相机层不是满铺素材、底是静态幕底，无"露边"问题，故不像 `slow-push-in` 那样钳制。
- **wall**：`.world`（`perspective: 1200px; perspective-origin: 50% 50%`，深灰径向幕底）→ `.cam`（`preserve-3d`）→ `.wall`（1700×540，`rotateY(−12°)`，`transform-origin: 850px 270px`，含 `.floor` 地面反光 `rotateX(80°)`）→ 三张 430×290 在 `left 140 / 640 / 1140, top 125`（中心 x 355 / 855 / 1355，y 270）。因为墙绕 x=850 转了 −12°，停靠目标用**旋转后的坐标** `wallX(cx) = 850 + (cx − 850)·cos12°`，否则每站偏心 11~14px。全景 `camTo(.61, 942, 270)`：透视下近端更宽，.61 时三张投影两侧各留 53px，目标 x 942 由投影包围盒居中解出（实验室 .72 / 850 会切掉第三张）。
  时间表：`0–0.8` 全景 → 每站 `move 1.0s power2.inOut` 到 `camTo(1.15, wallX(cx), 270)` + `hold 0.9`（其余照片从移动 0.5s 起 0.5s 内 `brightness .5 + blur 3px`；当前照片 `.ph` 从移动 0.7s 起 1.2s 内 `scale 1→1.03` linear）→ `6.5–7.7` 拉回全景（6.8 起 0.6s 全部复原）→ `7.7` 照片退场 0.4（错峰 0.04）→ `8.2` 结束。
- **timeline**：白底，`.cam` 宽 1600；一条时间线（`left 60, top 300, 1500×3, #1d1d1f`）+ 四张 240×160 上下交替（`(120, 90) / (480, 330) / (840, 90) / (1200, 330)`，中心 x 240 / 600 / 960 / 1320，站距 360）；日期 caption 22px 700 靠时间线一侧（上排在线下 318、下排在线上 266）、`nowrap`。停靠 `camTo(1.05, cx, 270)`：1.05 让邻站出画 24px（1.0 时邻站与画幅边齐平、邻站 caption 离边 6px，读作贴边），上排照片离顶 49.5；拉开 `camTo(.62, 780, 300)` 看全条（四张两侧各留 71）。
  时间表：`0` 第一站居中、全部 `.7` → `0.4` 第一站点亮（`brightness 1 + scale 1.03`，0.4s）→ `1.4 / 3.3 / 5.2` 横移到二三四站（`move 0.9 power2.inOut`，点亮从移动 0.5s 起）→ `7.1–8.2` 拉开（7.4 起 0.5s 全部复原）→ `8.2–9.4` 有意停留 → `9.4` caption + 时间线退、`9.44` 照片退（0.4，`power2.in`）→ `9.9` 结束。
- demo 两式硬切巡演（wall 0–8.2，timeline 8.2–18.1），灰色版式名标签是演示语境；tsx `layout="wall" | "timeline"` 单选，`durationFor(layout)` 给单式时长（258 / 309 帧），默认 `"tour"` = demo（555 帧）。

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| `stopZ` 停靠焦距 | wall 1.15 / timeline 1.05 | 放大 ≤1.2；wall <1.05 读不出"停下来看这一张"；timeline 1.0 邻站齐平画幅边（贴边感），>1.1 上排照片顶到安全边 |
| `wideZ` 全景焦距 | wall .61 / timeline .62 | 全景要装下全部照片且两侧 ≥48；wall 有透视，近端更宽——改墙角就重解 `wideAt` |
| `move` 站间移动 | 1.0 / 0.9s | <0.7 读作"甩过去"（转场语气），>1.5 观众等它到位 |
| `hold` 停靠 | 0.9 / 1.0s | **信息在 hold 里**；成片按"讲这一张要几秒"给；<0.6 白跑一趟 |
| `dim` / `blur` | wall .5 + 3px / timeline .7 | 其余照片的降权；wall 加景深虚化是"近处清远处糊"的空间暗示，timeline 平面不用 blur |
| `push` / `focus` | 1.03 | 停靠段当前图的防死微推 / 点亮；>1.05 读作第二次推镜 |
| `pull` 拉回 | 1.2 / 1.1s | 比单站移动略长（跨的距离更远）；拉回后必须有停留再收 |
| `tailHold`（timeline） | 1.2s | 看全条的有意停留；成片 = 口播结语那句 |
| `wallRy` | −12° | 3D 墙倾角；≤25° 才可读；换角度要重解 `wideZ` / `wideAt`（透视变了） |
| 站距 | 360（timeline） | 与停靠焦距一起决定邻站露多少；<300 一屏三站不像巡览，>420 横移太快 |

## 已知坑
- 用固定 `transform-origin`（center）+ 位移凑停靠——zoom 变化时甩出横向漂移，"镜头在找东西"；每站的目标必须反解到画心。
- wall 用未旋转的照片中心当目标——墙转了 −12°，投影中心偏 11~14px，每站都停偏一点；用 `wallX()` 旋转后坐标。
- wall 全景照抄 .72——透视下近端更宽，第三张被画幅切掉；全景焦距要按投影包围盒解，不按平面尺寸。
- 停靠段相机续走（套 `camEase` 末速非零）——本卡是停靠类，续走会让"停下来讲这一张"变成"路过"；防死交给图内微推。
- 停靠段什么都不动（无微推 / 点亮）——0.9s 全静止，观众以为卡帧（motion_check 也 FAIL）。
- 不拉回全景就收——观众看完三处不知道它们在整体的什么位置，巡游读作三个不相干的特写。
- timeline 停靠 1.0 且站距 360——邻站与画幅边齐平、邻站 caption 离边 6px，读作贴边；1.05 让邻站明确出画。
- timeline 照片不上下交替——四张一排，相邻两张的 caption 打架，且横移时整条读作一行缩略图。
- 两式在一镜里连用——wall 是"平级案例"、timeline 是"先后几站"，语法不同；demo 巡演只为看全。
- 拉回全景后不留停留直接切——观众刚回到全貌就被切走，等于没拉回；停留结束再退场。

## 复用指引
- Remotion/tsx（skill 首选）：template/cards/multi-still-tour.tsx——`layout` 单选（`"wall"` / `"timeline"`，默认 `"tour"` = demo 巡演），`srcs` 真图（wall 用前 3、timeline 用前 4），`labels` 图注；时长用导出的 `durationFor(layout)`（wall 258 / timeline 309 / tour 555 帧）；站数不同时改 `CONFIG.*.centers`（wall 同时改照片 `left`，timeline 同时改 `TL_POS` 与时间线长度），hold 要长改 `CONFIG.*.hold`。
- HTML/GSAP：demos/multi-still-tour/index.html——两个 `.preset` 各自完整，删掉一个即单式预览；`.ph` 整块换 `<img>`，`.tag` / `.cap` 换文案；核心可摘走：`CONFIG` + `camTo()` + `wallX()` + 两段 timeline 代码。
- 与 `stage-keyframe-tour` 的边界：那张是一张超出画幅的长页 + 多关键帧兴趣点巡游（`transform-origin` 每帧设到兴趣点）；本卡是**多张独立素材**挂在世界里 + 相机层 `origin 0 0` 反解，相机纪律同源、素材形态不同。单张长图用那张，多张图用这张。
- 与 layout.md 的接口：wall 全景三张两侧 ≥48（实测 53）、tag 20px（停靠时 23 ≈ 46@1080）；timeline 停靠上排照片离顶 ≥48（49.5）、caption 22px（停靠 23 / 拉开 13.6 ≈ 27@1080 最小可读边）、拉开时四张两侧 71；邻站出画是运镜语义，不算贴边。
- 剪辑软件对应物：AE 把几张图摆进一个合成（wall 加 3D 图层 + 摄像机），给摄像机 Position / Zoom 打关键帧、每站两个同值关键帧构成 hold，Easy Ease 后把手柄拉成 inOut；剪映 / CapCut 是合成后打"位置 + 缩放"多段关键帧，每站两个同值关键帧做 hold，压暗其余靠单独的亮度关键帧。素材站叫 "gallery wall dolly / timeline photo strip"。
- 音效：每段相机起步一记 `pk:counter-clock-tick-single`（vol .4，clip ~1），拉回 / 拉开一记压低的 `pk:transition-air-whoosh-powerful`（vol ≤.3）；**hold 段绝对不给声**。

## 动效范围
- 属于本卡的：相机层 `origin 0 0` + `camTo` 反解到画心的巡览停靠结构（每站缩放绕当前图发生）；"移动 power2.inOut → 真静止停靠 → 下一站 → 拉回全景 → 停留 → 与字同收"的节拍（wall 1.0 + 0.9 / 拉回 1.2；timeline 0.9 + 1.0 / 拉开 1.1 + 停 1.2）；停靠段当前图内部 1→1.03 微推 / 点亮 + 其余压暗（wall 加 blur 3）的焦点处置；wall 的 3D 墙（−12°、透视 1200、地面反光、旋转后坐标 `wallX`、按投影包围盒解全景）；timeline 的上下交替 + caption 靠线一侧 + 停靠 1.05 让邻站出画的几何。
- 不属于本卡的：demo 的灰调占位、"案例一~三"与"2019~2026"文案、版式名标签（巡演用）、时间线的颜色（#1d1d1f 可换）、白边卡的具体圆角 / 投影值、wall 幕底的具体色值。
- 迁移接口：`layout` 选式；`srcs` / `labels` 换素材文案；`hold` / `tailHold` 对齐口播；站数改 `centers`（+ 照片位 / `TL_POS`）；换画幅时几何按 960×540 等比缩放，`camTo` 里的 480 / 270 换成新画心；竖屏 timeline 改成竖向时间线（`camTo(z, 480, cy)` 纵向横移）。
- 底色要求：**wall 需要深灰径向幕底**（`radial-gradient(ellipse at 50% 40%, #26262e, #0f0f13 75%)`）——3D 墙上的白边照片靠深底 + 地面反光才读出"挂在墙上"的空间，白底上 rotateY 的照片像浮着的纸片，且其余照片的压暗 / 虚化在白底上成灰片；timeline 白底即可。

## 落位自检（2026-09-05 用户定版，选卡时抄进 SHOTBOOK 该镜自检列）
- **停靠居中**：每站 hold 中段截帧，当前图中心与画心 (480, 270) 偏差 ≤8px（wall 偏 >8 通常是没用 `wallX` 旋转后坐标）。
- **全景装得下**：wall 全景帧三张两侧 ≥48（实测 53）、timeline 拉开帧四张两侧 ≥48（实测 71）；改墙角 / 站距后重解 `wideZ` / `wideAt`。
- **hold 真静止 + 微推在走**：hold 段相机 transform 逐帧相等；当前图 `.ph` scale 在 1→1.03 单调走（或 timeline 当前站已到 1.03 且亮 1）。
- **邻站不贴边**：timeline 停靠帧邻站出画 ≥16（1.05 → 24），邻站 caption 被画幅切掉而不是离边 <48 悬着。
- **字号**：wall tag ≥20@960、timeline caption ≥22@960（拉开时 ≥13.6，缩到 390 宽复看仍可辨年份）。
- **一镜一式 + 有拉回**：SHOTBOOK 该镜只写一个 `layout`；时间表末尾有拉回 / 拉开 + 停留，退场与本镜结束对齐。
